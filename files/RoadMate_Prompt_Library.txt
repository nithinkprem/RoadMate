1. How to use this library
Each row below is one scoped prompt for an AI build tool (Lovable, Claude Code, or similar). Prompts are sequenced so each one produces a coherent, independently testable slice, referencing the schema and screens defined in the System Design Document and UI/UX Specification. Do not run a phase's prompts until the previous phase is in staging and its QA gate (see Test Plan, Section 1.3) has passed — later prompts assume earlier schema and auth patterns are already in place.
Numbering restarts within each phase for readability; treat each phase's block as its own sequence. Where a prompt says "screen", reference the matching screen ID from the UI/UX Specification (e.g. C3, W7, A9).
